Fix the `FILE_NAME` & `FILE_PATH` template variables, which always rendered as
empty strings. `FILE_NAME` is now the basename of the linted file.

**Breaking:** `FILE_PATH` is now the file's directory relative to the working
directory, with `/` separators on every OS (`.` for the working directory
itself), rather than an absolute directory. Headers generated by `--fix` are
now the same on every machine. Both variables are empty when the code has no
file name.
